## Tediware

This is the home of open source software created and maintained by Tediware, the developer-friendly, API-first, AI-native electronic data interchange (EDI) platform (https://tediware.com/)

### tediparse

tediparse is a fork of stupidedi. It is a streamlined version of the gem with some important bug fixes and improvements, as well as the removal of all X12 copyrighted content.
